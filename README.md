# The Pursuer
Published on Google Play
2D Hyper-Casual Space Survival Game

The Pursuer is a 2D hyper-casual mobile game set in space. Players must avoid incoming rockets, survive as long as possible, and challenge their reflexes.

Project Information
- Genre: Hyper-Casual
- Platform: Android
- Engine: Unity
- Programming Language: C#
- Project Type: Team Development (Oğuz Sevsel, Görkem Özbudak, Deniz Ölçe)
- Status: Published
